# МАТВІЙ: КУХНЯ ПРОТИ ВСІХ! Deluxe 2.1 Mobile

Кольорова 2D браузерна ретро-гра з п'ятьма рівнями, секретами, ворогами, суперлопаткою та фінальним босом ХРУМ-3000.

## Грати онлайн
https://helbq26.github.io/Matvii-Kitchen-Adventure/

## На комп'ютері
Відкрити `index.html` у Chrome або Edge. Enter: старт. A/D або стрілки: рух. Space: стрибок. J: атака. E: важіль. P/Esc: пауза. R: перезапуск. M: звук. C на заставці: продовжити відкритий рівень.

## На телефоні (Android Chrome)
- Відкрити посилання на GitHub Pages.
- Кнопка ▶ ГРАТИ запускає гру.
- Сенсорні кнопки: ◀ ▶ рух, ⬆ стрибок, ⚔ удар, ✋ взаємодія, Ⅱ пауза.
- Підтримується одночасне натискання руху і стрибка/удару.
- Вертикальний режим збільшує область ігрової сцени, а панель статусу показує прогрес.
- Горизонтальний режим показує все ігрове поле з кнопками обабіч.
- Кнопка ⛶ перемикає повний екран, якщо браузер це дозволяє.
- Для нового запуску натиснути ▶ ГРАТИ, для продовження вибрати ↩ ПРОДОВЖИТИ.
- Гра працює офлайн, якщо завантажити архів із файлами й відкрити `index.html` локально.

## Файли
- `index.html`: вебсторінка і панель керування
- `style.css`: комп'ютерний/мобільний дизайн
- `game.js`: фізика, рівні, вороги, бос
- `art.js`: ретро-графіка
- `mobile.js`: сенсорне керування і версії орієнтації

Зовнішніх бібліотек та серверної частини немає.
